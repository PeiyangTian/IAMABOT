# IAMABOT

IAMABOT 是我们为 MechMania 比赛实现的自动对战策略。它的整体思路不是让所有机器人简单地冲向敌人，而是把生产、经济、阵型、治疗、目标选择和终局转换放进同一个状态化控制器中。比赛引擎会为位于右上方的队伍镜像整个世界，因此正式比赛中 A、B 两侧都会加载完全相同的 `AdvancedStrategy`，所有位置和方向都从当前的 `GameState` 动态计算，不需要为某个出生方向编写特殊逻辑。

在生产阶段，策略会立即利用开局 token 加速扩张，并逐步形成 18 个 Battle、8 个 Extractor 和 6 个 Healer 的 32 单位满编阵容。前两个 Battle 提供最基本的开局保护，随后优先补齐矿点能够同时容纳的 8 个 Extractor，再根据舰队规模增加火力和治疗单位。每个 Extractor 都会被分配到矿点周围不同的合法位置，以避免多个机器人重叠、碰撞或争抢同一个采矿位置；当比赛进入无法继续生产机器人的终局阶段后，继续积累 token 已经没有价值，所以这些 Extractor 会停止采矿，移动到运载目标周围并转化为额外的占点力量。

主力战斗群会在 payload 周围形成内外两层分散阵型，而不是堆在目标中心。内圈负责稳定控制目标，外圈提供更多射击角度，机器人之间还会根据距离产生局部排斥力，从而主动拆散完全重叠或距离过近的单位。这种布阵既能减少碰撞，也能降低敌方一次溅射攻击同时命中多个单位的概率。发现敌人接近己方矿点时，距离基地最近的两个 Battle 会自动转为守卫，其余部队继续争夺 payload；当主力规模足够且局势没有严重落后时，少量后排 Battle 还会寻找暴露的敌方 Healer 或 Extractor 进行侧翼攻击，但不会为了追击远处目标而放弃比赛目标。

战斗系统会为射程内的敌人计算动态优先级，正在占领 payload 的单位、能够被一发击杀的残血单位、敌方 Healer 以及密集站位中具有溅射价值的目标都会获得更高分数。射击前还会检查武器冷却、距离、墙体视线、payload 和矿点的实体遮挡、目标的短暂无敌状态，以及机器人在本 tick 完成转向后是否真正瞄准目标。由于被击中的机器人会暂时无敌，多个友军同时攻击同一目标通常会浪费后续炮火，因此准备开火的 Battle 会依次预订不同目标，把一次齐射分配到多个有效目标上。

Healer 会根据友军损失的生命值、单位类型、与 payload 的距离和自身赶到目标所需的距离选择治疗对象，并严格遵守规则允许的治疗叠加上限。多个 Healer 不会全部挤在同一个位置，而是从不同方向跟随受伤单位，同时预测目标下一 tick 的位置；只有当目标处于治疗距离、视线范围和治疗扇形内时才会启动治疗。暂时没有需要治疗的单位时，Healer 会在 payload 后方组成支援阵型，在保持治疗覆盖的同时减少自己暴露在最前线的时间。

完整策略每一 tick 都需要进行寻路、阵型计算、目标评分、治疗分配和射线检查，因此控制器还会持续读取比赛提供的 compute budget。当剩余预算低于安全阈值时，它会临时切换到计算量更低的备用控制逻辑，继续生产、采矿、占点和基础治疗，让预算逐渐恢复，避免因为一次计算超支而连续多个 tick 无法行动。正式入口位于 [`strategy/main.py`](strategy/main.py)，主要控制器位于 [`strategy/brain.py`](strategy/brain.py)。

## 本地运行

安装 Rust、Python、Git 和 `mm-cli` 后，可以在仓库根目录运行下面的命令进行正式策略的镜像自对弈：

```sh
mm-cli run --quiet
```

仓库还保留了一个只用于本地验证的主动基准策略。下面两条命令会分别让正式策略处于 A 队和 B 队，用来验证策略不会依赖某一个阵营方向；如果没有设置该环境变量，比赛双方都会使用正式的 `AdvancedStrategy`。

```sh
MM_IAMABOT_LOCAL_AB=advanced-a mm-cli run --quiet
MM_IAMABOT_LOCAL_AB=advanced-b mm-cli run --quiet
```

完成本地验证并登录比赛账号后，可以使用 `mm-cli submit` 上传当前 `strategy/`。正式提交会替换服务器上的现有版本，因此应当在确认测试结果后再执行。
